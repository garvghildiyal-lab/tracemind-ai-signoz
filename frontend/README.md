# TraceMind AI Frontend

React frontend for the TraceMind AI observability platform.

## Features

- Dashboard
- KPI Cards
- Response Time Charts
- AI SRE Analysis
- Incident Timeline
- AI Copilot

## Run Locally

```bash
npm install
npm run dev
```

Default URL:

```
http://localhost:5173
```

The frontend communicates with the FastAPI backend running on:

```
http://127.0.0.1:8001
```
